## Featured

**[GravPool](https://github.com/ghostedmyself/gravpool)** — turn Google Antigravity
accounts into a managed OAuth credential pool: auto-refresh, live quota, account
rotation, a zero-dependency web dashboard, and an OpenAI-compatible endpoint —
all in one command.

```bash
python -m gravpool.cli gui --auth-dirs auth
# dashboard + /v1 endpoint on one port
```
